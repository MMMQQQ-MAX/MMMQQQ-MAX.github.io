# 关于

你好，欢迎来到「时光沙漏」。

这里只是记录生活的地方——今天吃了什么、去了哪里、看到什么、想了些什么。没有什么宏大叙事，就是一些普通日子的存档。

## 关于这个网站

- 用 [Astro](https://astro.build) 和 [Fuwari](https://github.com/saicaca/fuwari) 主题搭建
- 托管在 GitHub Pages 上，不花钱
- 文章都是 Markdown 文件，直接放在仓库里
